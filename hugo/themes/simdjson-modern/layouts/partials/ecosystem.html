fastsimdjson: simdjson for Python

Our official Python binding is a drop-in replacement for the json module's loads, load, dumps and dump, and it can be over 3× faster than the standard library.

  • Lazy parse when you need only part of a document, with JSON Pointer.
  • NDJSON streams, on many threads with free-threaded Python.
  • dumpb writes the same bytes as orjson.dumps, as fast as orjson.
  • NDJSON to Apache Arrow tables and back, for pyarrow, polars or DuckDB.
  • JSON to MessagePack and back, 3 to 4× as fast as orjson with ormsgpack.

Wheels for Linux, macOS and Windows, Python 3.10 to 3.15, including free-threaded Python.

# pip install fastsimdjson
import fastsimdjson

fastsimdjson.loads(b'{"a": [1, 2.5, "x", true, null]}')
# {'a': [1, 2.5, 'x', True, None]}

doc = fastsimdjson.parse(open("twitter.json", "rb").read())
doc.at_pointer("/statuses/0/user/name")
The simdjson family

JSON to Arrow and MessagePack

Two new C++17 libraries built on simdjson. Like simdjson, each is one header and one source file, with a C interface too.

Arrow

simdjson_arrow

Reads newline-delimited JSON into Apache Arrow record batches, and writes them back, on one thread or many. Several times faster than Arrow C++'s own JSON reader. Results are Arrow C Data Interface structures, usable without a copy by Arrow C++, nanoarrow or DuckDB. Read more →

MessagePack

simdjson_msgpack

Converts JSON to the most compact MessagePack and back, one document or NDJSON streams on many threads. Faster than the usual ways of doing it in C and C++ (yyjson, RapidJSON with mpack, nlohmann::json). Read more →
