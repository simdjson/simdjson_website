sjq: simdjson on the command line

sjq is a command-line JSON processor that reads the jq language. The filters you write for jq work with sjq, and on large inputs they run ten to a hundred times faster.

sjq '.statuses[] | {id, name: .user.name}' twitter.json
sjq -c 'select(.status == 404) | {ip, url}' access.ndjson
sjq -r '.[] | "\(.id)\t\(.name)"' users.json

Install

Linux and macOS:

curl -fsSL https://raw.githubusercontent.com/simdjson/sjq/main/install.sh | sh

Windows (PowerShell):

irm https://raw.githubusercontent.com/simdjson/sjq/main/install.ps1 | iex

The scripts download the binary for your system from the latest release and check its SHA-256 checksum. The Linux binaries are static (x86-64 and ARM64), the macOS binary runs on Apple silicon and Intel Macs, and Windows has x64 and ARM64 builds. One binary is enough for each system: simdjson detects the processor when sjq starts and picks the fastest code it supports.

Performance

We compared sjq with jq 1.8.2 on two inputs built from simdjson’s twitter.json sample: 1 GB of newline-delimited JSON (one tweet per line) and one 840 MB document. The outputs of jq and sjq are identical. “sjq” is the default, which filters large newline-delimited files on all cores; “sjq –threads 1” uses one core.

How

sjq parses JSON with simdjson. When a filter only navigates and selects, sjq runs it with simdjson’s On-Demand API, which parses only what the filter reads and copies the output from the input. Files are mapped in memory instead of being copied, and large newline-delimited files are filtered on all cores, with the results written in order.

Compatibility

sjq implements the jq 1.8 language: paths, select, map, reduce, foreach, function definitions, string interpolation and formats such as @csv, assignment (=, |=, +=), del, destructuring, regular expressions, dates, input and inputs, and the usual options (-r, -c, -s, -n, -R, --arg, --argjson, …). 728 of the 781 tests of jq’s own test suite pass, and the jq tutorial runs unchanged. The documentation lists the differences.
